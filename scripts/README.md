# HTML Result Report

`make_result_tables.py` reads SSM-GED benchmark summaries and creates comparison
tables for CDE against the best result from the other algorithms. It now writes
one HTML report by default.

## Input

The default input is the `summary.tsv` generated by `compare.sh`.

The script expects columns like:

```text
dataset_group
dataset
query_group
query
threshold
status
cde_match_run_ms
treespan_run_ms
```

Algorithm columns are detected automatically from suffixes such as
`_run_ms`, `_count`, and `_recursion_calls`.

## Run

From the repository root:

```bash
python3 -B scripts/make_result_tables.py result/20260426_025928/summary.tsv
```

You can also pass the result directory directly:

```bash
python3 -B scripts/make_result_tables.py result/20260426_025928
```

## Output

By default, output is written beside the input `summary.tsv`.

Generated files:

```text
report.html          Full detailed-results HTML report.
speedup_by_t.html    Standalone threshold-oriented speedup report.
```

The detailed report contains one detailed result table per comparison object.
The standalone threshold report places `t` values across columns and only
compares final running time. Each threshold cell shows the speedup, CDE running
time, and the best non-CDE running time.

## Speedup

For the default time metric, smaller is better:

```text
speedup = best_other_run_ms / cde_match_run_ms
```

Meaning:

```text
speedup > 1   CDE is faster, shown as green.
speedup < 1   CDE is slower, shown as red.
speedup = 1   Tie, shown as white.
```

The farther the ratio is from `1`, the deeper the color.
